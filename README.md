
## ✨ الميزات

- 📚 **20 درس** محادثة عملية
- 🧙 **المفتاح السحري** - مفردات أساسية منظمة بـ 7 فئات
- 🔊 **نطق صوتي** - استمع للنطق الإنجليزي الصحيح
- 📊 **تتبع التقدم** - شاهد إنجازاتك
- 🌐 **دعم اللغات** - العربية والإنجليزية
- 💾 **حفظ تلقائي** - يتذكر تقدمك

## 📚 المحتوى

### الدروس الأساسية (20 درس):
التحيات، التعريف بالنفس، الطعام والشراب، الوقت والروتين، التسوق، السفر، العمل، الهوايات، الصحة، الأهداف والأحلام، العائلة، الألوان، الملابس، الطقس، المدرسة، التكنولوجيا، البيئة، المستقبل، النجاح والتحفيز، المحادثة اليومية.

### المفتاح السحري (7 فئات):
- 🏠 عالمي الصغير
- 👨‍👩‍👧‍👦 أبطال قصتي
- 🏃 الحركة والحياة
- 🌡️ صفاتي ومشاعري
- 🕰️ الزمان والمكان
- 🔗 أدوات الربط
- 🧠 الضمائر والمحددات

## 🚀 كيفية الاستخدام محلياً

```bash
cd /workspaces/EN1
python3 -m http.server 8000
```

ثم افتح المتصفح على: `http://localhost:8000`
